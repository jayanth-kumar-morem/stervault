external dependencies, local blockchain infrastructure, and application components.

Initial Setup: 
* Run setup-pyth.ts to configure Pyth price feeds 
* Execute clone-tokens.ts to create test tokens 
* Start local validator with anchor-localnet 
* Run integration tests with anchor-test Active Development: 
* Use dev for local frontend development 
* Use dev:devnet for testing against live devnet 
* Deploy with aws-deploy for production releases The setup scripts create reusable configuration files in the price-feeds/ and keys/tokens/ directories that persist across development sessions.
