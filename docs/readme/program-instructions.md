Account Structure: * signer: User wallet (mutable, signer) * user_global_state: PDA account storing global user data * system_program: Solana system program Process: 
* Creates UserGlobalState account using PDA seed ["user_global", signer.key()] 
* Initializes empty deposited_mints vector 
* Sets user pubkey and bump seed Sources: anchor/programs/lending/src/instructions/init_user.rs4-27 ### init_user_token_state Initializes user state for a specific token mint, enabling deposits and borrowing for that token.

* Creates UserTokenState using PDA seed [signer.key(), mint_address.key()] 
* Initializes timestamps for interest calculations
